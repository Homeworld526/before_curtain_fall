# 《落幕之前》美术资源规范

## 命名规范
### 全英文命名，可用 小写字母 数字 _ 拼接组合
### 人物资源图，可遵循 role_角色名(首字母)_立绘类型_编号形式命名，比如 role_zhx_head_1,或者 role_xl_stand_3
### 场景图，CG图也类似，比如 scene_city_01, cg_xl_02
### UI资源，尽量让同一个界面的资源有相同前缀即可

## 文件格式
### 透明图片、立绘、UI、图标和图集导出为 `.png`。
### 不需要透明通道的背景和 CG 优先导出为 `.jpg`。
### 源工程文件使用的 `.psd` 文件不需要放进项目里

## 资源尺寸约定
### 导出后检查，如果存在大量空白像素，则考虑缩边重新导出
### 单张图尺寸不要超过2048X2048,CG图可翻倍，硬盘空间占用不超过5M
